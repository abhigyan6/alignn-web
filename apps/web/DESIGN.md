# Alignn design system

Approved product journey: see PRODUCT.md. User delegated the visual redesign and asked for competitor research plus selected starred design/motion skills. This is the resulting implemented system, not a promise of feature completeness.

The durable system is documented in ../../.interface-design/system.md. globals.css defines shared semantic tokens, responsive chrome, cards, public landing, discovery and detail layouts. Scoped modules own auth/onboarding/workspace/loading styles. Manrope, the Alignn loop and forest action identity are retained; layout and hierarchy were replaced around student tasks.

Primary action: forest #145640 on white/light-neutral #f7f8fa. Ink #182821; muted #65726c; line #e1e6e1; supportive lime #d9eeaa and category lilac #eeebfa. Standard focus #a15807. Surface/control radii 16/10px. No fabricated logos or social proof. Platform names describe provenance rather than endorsement.

Components: page heading, search, category controls, sortable opportunity grid, qualified source card, independent save control, decision/detail page, saved/application tabs, profile steps, shared Clerk shell, task-specific skeletons and pending brand indicator. Relevant accessibility/feedback/motion limits and verification boundaries live in the interface system document.
